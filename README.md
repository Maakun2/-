# ハードウェア基礎論

ハードウェア基礎論の授業のノートを、このリポジトリに書いていきます。

## ノートの使い方

- 紙のノートには授業中の図・計算・説明を記録します。
- GitHubには授業後に要点、理解したこと、疑問点、復習問題を整理します。
- 各回に紙ノートのページ番号を書き、必要な写真や図は `images/` に保存します。
- まずは授業後5〜10分で「要点3つ・疑問1つ・復習問題1つ」を書きます。

## ファイル構成

```text
README.md       # 授業の概要と各回へのリンク
notes/
  01.md         # 第1回のノート
  ...

images/         # 回路図や紙ノートの写真
```

画像名は `01-circuit.jpg` のように授業回を先頭に付けると探しやすくなります。
